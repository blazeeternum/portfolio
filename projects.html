BlazeEternum File Secure Encryptor v6.0.0 - Personal Project

BlazeEternum Secure Encryptor Software is a secure file encryption tool designed to protect sensitive data from unauthorized access. It has added support for post-quantum encryption algorithms, ensuring long-term security against future quantum computing threats. It using the Kyber-1024 algorithm, which is a finalist in the NIST Post-Quantum Cryptography standardization process, providing robust security against quantum attacks.

Technologies Used:

Post-Quantum: Kyber-1024 (NIST FIPS 203, NIST Security Level 5)

Encryption: AES-256-GCM + HKDF-SHA256

Key-file KDF: Argon2id (64MB memory, 3 iterations, parallelism 4)

Programming Language: Rust
